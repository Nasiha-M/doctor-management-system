\# Doctor Management System



A full-stack Doctor Management System developed using Python Django and Flutter.



\## Project Overview



The Doctor Management System is designed to support interactions between doctors and patients through a mobile application and a web-based backend.



The project consists of two main components:



\- \*\*Backend:\*\* Python, Django and MySQL

\- \*\*Frontend:\*\* Flutter and Dart



\## Technologies Used



\### Backend

\- Python

\- Django

\- MySQL

\- Machine Learning (K-Nearest Neighbors)



\### Frontend

\- Flutter

\- Dart
